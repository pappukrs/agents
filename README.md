# agents

30-day AI Agent Engineering roadmap and daily build log.

- **Start:** 2026-10-13
- **Hackathon:** ~2026-10-23 (end of Day 10)
- **Format:** 3 blocks every day — Learn → Build → Test/Deliver
- **LLM:** Google Gemini (`@google/genai`, key in `GEMINI_API_KEY`)
- **Stack:** TypeScript + Node.js (agent backend), Python (ML / fine-tuning), PostgreSQL + pgvector (retrieval), React/Next.js (dashboard)

## Layout

```
ROADMAP.md        full 30-day plan
days/dayNN/       one folder per day: notes.md + code
project/          the hackathon product (AI Lead Intelligence Agent)
```

## Daily routine (~2.5–3 h)

| Block | Time | Output |
|-------|------|--------|
| Learn | 60 min | `days/dayNN/notes.md` |
| Build | 60 min | working code in `days/dayNN/` or `project/` |
| Test / Deliver | 30–60 min | test results + short writeup in notes |

See [ROADMAP.md](ROADMAP.md) for the plan.
